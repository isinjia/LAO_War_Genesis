# 밸런스 채점과 조정

`?unlock=1&balance=1`로 열면 `tools/balance.js`가 실린다. 콘솔에서 `BAL.all()`을 실행하면 헤드리스 전투(`GAME.sim`)로 네 영역을 100점 만점으로 채점한다. 영역별로 따로 돌릴 수도 있다: `BAL.level()`, `BAL.difficulty()`, `BAL.unitsAndRoles()`.

점수는 고정된 자동 지휘관(봇)으로 게임을 게임 자신과 비교한 값이다. 사람의 실력이나 재미를 측정하지 않는다.

## 자동 지휘관

- 발전 효율을 3단계까지 올린다.
- 탱커가 둘 미만이면 탱커부터 배치하고, 그다음 준비된 대원 중 가장 비싼 대원을 위해 전력을 모은다.
- 적이 셋 이상 모이거나 보스가 사정권에 들면 오르카 포격을 쏜다.

## 경제가 주는 성장 수준

- 기대 레벨: 각 스테이지 첫 클리어 XP와 재도전 1회(절반)를 8장 카드에 나눠 올렸을 때의 전투 레벨. 1-1은 L1, 8-10은 L9.
- 기대 덱: 시작 대원, 지금까지의 챕터 보상, 시작 10연 제조에서 흔히 나오는 A 대원(밴시·에이미), 2장부터 다프네, 4장부터 안드바리, 5장부터 첫 SS(라비아타).

## 채점 기준

| 영역 | 기준 |
|---|---|
| 레벨 밸런스 | 표본 40개 스테이지(각 장 1·3·5·7·10). 기대 덱·기대 레벨로 기지 30% 이상 남기고 클리어(70%). 2레벨 낮은 덱이 패배하거나, 기지가 15%p 이상 덜 남거나, 클리어가 1.2배 이상 느림(30%). L3 미만은 레벨 차이를 묻지 않는다 |
| 난이도 완성도 | 각 표본을 클리어하는 최저 레벨 R. R이 기대 레벨 E 이하이고 E-4 이상(35%), 스테이지 순서와 R의 순위 상관(25%), 정예·보스가 같은 장 직전 표본 이상(15%), 이웃 표본 사이 3레벨 넘는 벽 없음(15%), 하드 1-10·8-10이 같은 덱으로 노멀보다 2레벨 이상 요구(10%) |
| 캐릭터 밸런스 | 표준 전투(4-4, 기본 대원 레프리콘·밴시와 함께 150초)에서 (가한 피해 + 받아낸 피해 x0.6 + 요새 피해 x0.5) / 쓴 전력. 등급 보정 후 같은 등급 중앙값의 ±35% 안이면 100점, 2.6배에서 0점. 공성 대원은 요새 피해로 잰다 |
| 캐릭터 활용도 | 역할 9종. 두 등급 이상에 2명 이상(20), 자기 상황에서 최고 대원이 다른 대원 중앙값의 1.3배 이상(60), 표준 전투에서 같은 등급 대비 0.8배 이상(20) |

| 역할 | 대원 | 전용 상황 |
|---|---|---|

| 전투함 | 흐레스벨그(S), 콘스탄챠·엠프리스(SS) | 장거리 포격 적과의 장기전 |
| 방어 타워 | 안드바리(A), 이터니티(SS) | 드론·나이트 칙 돌격(단독) |
| 단일 공격 | 사격·저격형 | 장갑 개체 |
| 범위 공격 | 포격·근접·전격형 | 약한 개체의 대군 |
| 다수 배치 | 브라우니 3기(B), 다프네 2기(B), 님프 2기(A) | 대군 |
| HP 탱킹 | 방벽·타워·전투함 | 폴른·레기온 근접 압박(단독) |
| 마릿수 탱킹 | 다수 배치 대원 | 램파트·폴른의 단일 공격(단독) |
| 회피 탱킹 | 발키리(S), 제로·머큐리(SS) | 약한 공격의 대군(단독) |

## 조정 도구

- `TUNE` (`js/data.js`): 대원별 체력·공격 배율. `BAL.unitsAndRoles()`의 등급 내 비율로 `(1/x)^0.5~0.6`씩 반복 조정했다.
- `DIFF` (`js/data.js`): 스테이지별 적 강도·요새 체력 배율. `BAL.calibrate()`는 기대 레벨보다 2레벨 낮은 덱이 기지 20~60%를 남기고 이기는 배율을 찾는다. 표본 사이는 선형 보간한다. 1장은 입문 구간이라 `k^0.6`으로 완화하고 1-1은 1.5로 고정했다.
- 새 적(원작 몬스터): 스토커(저격), 스카우트(돌격), 스피커(회복). 각각 마릿수 탱킹, 방어 타워, 단일 집중 화력의 가치를 만든다.

측정 직전 변경: 다수 배치 대원은 필드 40칸 중 한 배치당 1칸만 쓴다(3기면 각 1/3칸, 전체 개체 상한 80). 브라우니 3기 같은 분대가 칸을 채워 비싼 대원을 못 내보내던 교착을 없앴다. 노멀 8-10 배율 0.8(기대 L9 대비 L6으로 클리어).

남은 문제
- 하드 8-10은 기대 덱으로 레벨 15에서도 클리어되지 않는다(엔드게임 도전 과제로 남김).
- 8-7은 기대 레벨 9 대비 L4로 클리어되어 다소 쉽다.
- 측정은 판마다 편차가 있어(같은 덱도 승패가 갈리는 보스전) 점수는 ±3 정도 흔들릴 수 있다.
- 점수는 자동 지휘관 기준이며 실제 손 플레이 체감은 별도 확인이 필요하다.

## V1.30 체감 밸런스 (어렵다 · 탱커가 녹는다 · 출격을 너무 자주 해야 한다)

플레이어 의견 세 가지를 재려고 `BAL.feel()`에 세 영역을 더했다. 종합 점수는 일곱 영역의 평균이다.

| 영역 | 기준 |
|---|---|
| 체감 난이도 | 보통 플레이어(`casualBot`): 발전 효율 2단계까지, 1초에 한 번 판단, 무작위로 카드 하나를 골라 그 전력이 모이면 출격, 포격은 충전되는 대로. 기대 덱·카드 레벨 10으로 표본 40곳을 기지 25% 이상 남기고 클리어(아슬아슬한 승리는 절반) |
| 탱커 생존 | 기본 지휘관 전투에서 보호기(원작 병과, 타워·전투함 제외)가 전장에 있는 시간의 스테이지별 중앙값. 20초 이상 만점, 8초 이하 0점 |
| 조작 부담 | 같은 전투에서 모든 대원이 전장에 있는 시간의 스테이지별 중앙값. 30초 이상 만점, 10초 이하 0점 |

조정
- 보호기(원작 병과: 노움·운디네·아자젤·사라카엘·이터니티·슬레이프니르·블랙 리리스·블라인드 프린세스)는 받는 피해 x0.6 (`GUARD_DR`, js/game.js).
- 대원 밸류 x2 (`VALUE`, js/data.js): 모든 대원의 체력·공격 x2, 출격 비용 x2, 전력 최대치 x2. 초당 전력 수입과 발전 효율 비용은 그대로라 같은 시간에 내보내는 전력은 같고, 대원 수만 절반이 된다.
- 적 공격 배율 1.4 → 1.0 (`TUNE_EATK`).
- `DIFF`: 4-7~5-10 x0.8, 그중 4-7·5-5·5-10 추가 x0.85, 2-10 x0.7, 6-3 x0.56, 7-10 x0.85.
- `TUNE`: 하르페이아·님프·우르 하향, 엠프리스·임펫 상향(같은 등급 중앙값 대비 비율의 `(1/x)^0.55`).
