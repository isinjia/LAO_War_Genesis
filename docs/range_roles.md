# 역할별 사거리와 전열 배치 조정

검사일: 2026년 10월 25일

## 배치 기준

| 구분 | 사거리 | 배치 의도 |
|---|---|---|
| 보호기 | 1.1~1.4 | 적에게 가장 가까이 접근해 전열 형성 |
| 근접 대원 | 1.9~2.3 | 보호기 뒤에서 근접 공격 |
| 원거리 대원 | 3.0 이상 | 무기에 따라 후열과 장거리 구분 |
| 고정 지원 포대 | 11.2 | 지원기 안드바리의 기존 특성 유지 |

같은 구간에서도 무기와 특성에 따른 차이를 남겼다. 원작 병과가 보호기인 블랙 리리스와 블라인드 프린세스도 보호기 기준을 적용했다. 프랭스터 머큐리는 지원기지만 근접 무기를 쓰므로 근접 구간에 둔다.

이터니티는 고정포대 속성을 해제하고 전진하는 보호기로 바꿨다. 원본 이동 애니메이션이 있는 것을 확인했다. 체력·공격력·비용·이동속도·재배치 시간은 그대로 유지했다.

공중 보호기에 지상 아군을 대신 보호하는 규칙은 추가하지 않았다. 지상 근접 적은 계속 공중 대원을 공격하거나 지상 장애물로 취급하지 않는다. 사거리 차이는 보호기가 합류한 뒤의 교전 위치를 나누는 방법이며 즉시 앞으로 이동시키거나 적의 표적을 강제로 바꾸는 기능은 아니다.

## 대공 안내

기존 사거리 2.4 기준을 유지한다. 총기 원거리로 바뀐 발키리는 대공이 가능하고, 짧은 근접 무기로 분류한 대원은 대공 불가로 표시된다. 다음은 직접 대공 가능 여부가 바뀐 대원이다.

| 대원 | 이전 | 변경 |
|---|---|---|
| 발키리 | 불가 | 가능 |
| 이터니티 | 가능 | 불가 |
| 브륀힐드 | 가능 | 불가 |
| 프랭스터 머큐리 | 가능 | 불가 |

실피드·하르페이아 같은 요새 전용 기체는 사거리가 길어도 적 비행 대원을 직접 겨냥하지 않는다. 상세 정보에는 요새 전용으로 표시하고, 일일 작전의 필수 대공 대원 선정과 패배 안내에서도 제외했다.

## 검증

- 실제 전투 엔진을 사용한 전열·비행 검사 14개 통과.
- 노움·블랙 리리스·블라인드 프린세스·이터니티를 공격기보다 10초 늦게 출격시켜도 합류 후 앞에 서는지 검사했다. 위치 검사는 움직이지 않는 시험 적을 사용해 사거리 효과를 분리했다.
- 운디네·아자젤·사라카엘·슬레이프니르는 지상 근접 적이 통과하고 공격하지 않는지 확인했다.
- 지상 근접 다섯 대원은 비행 적에게 피해를 주지 않고, 레프리콘은 같은 적에게 피해를 주는 양성 대조를 확인했다.
- 일반 80개·어려움 80개를 실제 카드 10레벨 보상 편성으로 검증했다. 기본 편성 네 번씩 640회와 보강 편성 140회, 총 780회가 기존 시간·기지 잔여 체력 기준을 통과했다. 최고 등급 대원은 필수가 아니다.
- 사거리 변경 후 어려움 세 번째 장 여섯 번째 작전의 적 공격력과 여섯 번째 장 여덟 번째 작전의 적·요새 체력을 소폭 보완했다. 출현 구성과 보상은 유지했다.
- 일일 작전 120개를 생성해 공중 적이 있는 73개 편성에 실제 대공 가능한 대원이 최소 두 명 포함되는지 확인했다.
- 브라우저 기능 검사 22개 통과.

자동 전투 통과는 모든 편성이나 사람의 승률을 보장하지 않는다. 이번 변경은 사거리와 전열 역할에 한정하며, 같은 편끼리의 밀집 해소·등급별 효율 재설계·난이도 곡선 전체 평가를 완료했다는 뜻은 아니다.
