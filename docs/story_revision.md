# 메인 스토리와 인물 설정 개정

이 캠페인은 원작의 공식 사건이 아니라, 원작 인물이 참가하는 별도 해안 구출 작전이다. 철충이 구조 신호와 전투 기록을 이용한다는 설정도 이 캠페인의 창작 설정이다.

## 사건의 연결

| 장 | 사건과 다음 장으로 이어지는 이유 |
|---|---|
| 1 | 내륙 수색대를 지원할 귀환 거점 설치. 정기 연락이 끊기고 반복되는 구조 신호 수신 |
| 2 | 녹음된 구조 신호를 발견. 이송 흔적으로 생존 가능성을 확인하고 추적 |
| 3 | 기록에서 수용 인원과 위치 확인. 가까운 포로 12명부터 구출하기로 결정 |
| 4 | 포로 12명 구출. 적이 아군 편성과 사격 간격까지 기록했음을 발견 |
| 5 | 포격 아래서 부상자와 차량을 해안으로 철수. 서쪽 신호에 실제 응답이 섞임 |
| 6 | 피닉스와 수송대 구조를 위해 탄약과 정보 회수를 포기. 흐레스벨그의 생존 확인 |
| 7 | 이전 전투 기록을 이어받은 처형인에 대응해 진형 변경. 부상자의 퇴로 확보 |
| 8 | 반복 녹음에 흔들리지 않고 생존 인원을 확인한 뒤 지역 중계망 차단. 해안 거점으로 귀환 |

포로, 가짜 구조 신호, 재등장하는 처형인과 왕좌를 같은 사건으로 연결했다. 최종 승리의 범위는 해당 해안의 지휘망으로 제한한다. 다른 전선의 철충까지 전부 정지하지 않는다. 흐레스벨그는 봉인된 존재가 아니라 부상자를 지키던 수색대원으로 앞 장에서 예고한다.

## 말투보다 먼저 수정한 인물의 역할

| 인물 | 수정 방향 |
|---|---|
| 노움 | 졸린 유탄 담당에서 발포 콘크리트 탄으로 동료의 퇴로를 지키는 병사로 수정 |
| 임펫 | 화염방사수라는 묘사 제거. 포탄과 폭발을 다루는 행동으로 표현 |
| 발키리 | 호쾌한 돌격대장 대신 과묵한 정찰과 조용한 접근으로 표현 |
| 님프 | 신호 해독 전문가라는 설정을 걷어내고 현장 흔적과 길을 확인하는 역할로 표현 |
| 레이븐 | 냉정한 저격수 대신 친근한 말투와 엄호 사격으로 표현 |
| 운디네 | 냉각 설비 담당이라는 설정 제거. 항공 정찰과 자신감 있는 말투로 표현 |
| 피닉스 | 불사·부활 능력을 가진 존재처럼 묘사하지 않고 고립된 아군으로 표현 |
| 테티스 | 만능 회로 분석가 대신 관측 결과를 장난스럽게 전하는 인물로 표현 |
| 흐레스벨그 | 신비한 봉인 설정 제거. 부상자와 소대원의 생환을 우선하는 판단으로 표현 |
| 라비아타 | 지시를 설명하는 진행자보다 귀환 인원과 사령관을 챙기는 행동으로 표현 |

브라우니의 군대식 말투, 레프리콘의 '각하', 발키리의 '지휘관 각하' 등은 장면에 맞게 사용한다. 웃음소리나 유행어를 매 대사에 반복하는 방식은 피한다. SS 에피소드도 즉각적인 절대 신뢰, 트라우마의 갑작스러운 해소, 근거 없는 초능력과 동료를 해친다는 농담을 줄인다.

## 검토 근거와 한계

로컬에 보관된 원작 대사 자료를 직접 확인했다.

- `E:/LAO_MINI_GAME/7_LAO_3Kingdom/js/lines_data.js`: 로비·상호작용 대사
- `E:/LAO_MINI_GAME/7_LAO_3Kingdom/tools/lao_data.json`: 원작 합류 대사
- `E:/LAO_MINI_GAME/6_LAO_Laket_Monster/docs/speech_guide.md`: 보조 말투 가이드

초기 검토에서 헬라·블라인드 프린세스·파프니르는 로컬 자료가 부족했다. 이후 사용자가 제공한 나무위키 문서 본문과 아래 전술 교본의 합류·기본 대사를 확인해 세 에피소드를 다시 썼다. 전술 교본은 원작 대사를 수록한 팬 데이터베이스이며 공식 운영 문서는 아니다. 에피소드 자체는 설정을 참고해 새로 쓴 창작 장면이다.

- [헬라 기본 정보·대사](https://lo.swaytwig.com/units/BR_Hela): 인간님 호칭, 마스크에 따른 인격·말투 변화, AGS 잔해 조종, 가족 같은 동료를 바라는 마음을 반영했다. 가동 중인 AGS를 자유롭게 지배하는 능력으로 확대하지 않는다. 카드의 잘못된 '저승의 번개' 설명도 교체했다.
- [블라인드 프린세스 기본 정보·대사](https://lo.swaytwig.com/units/PECS_BlindPrincess): 성녀가 배우 자신의 배역이라는 자각, 연기 중 용살자 호칭과 평소 사령관 호칭, 맥주·과자를 좋아하는 털털함을 반영했다. 시력이 없다는 설정을 유지하고 대화 상대를 발소리로 알아차리도록 썼다. 기본 모습에 별도 스킨의 용의 마녀 인격을 섞지 않는다.
- [파프니르 기본 정보·대사](https://lo.swaytwig.com/units/BR_Fafnir): 거침없는 반말, 보물에 대한 애착과 부하를 챙기는 결정을 함께 담았다. 주피터의 생체 전기 증폭·정전 능력을 수리 기술이나 신적인 번개 능력으로 확대하지 않는다. 원작 사건의 하카를 다시 보유한다고 전제하지도 않는다.

전투용 역할·스탯·공격 효과는 이번 스토리 개정의 검증 범위에 포함하지 않는다. 헬라의 기존 번개형 전투 효과 역시 잔해 조종 효과로 교체한 상태는 아니다.

`node tools/story_test.js`로 장면 연결 키, 화자, 배경, 대원 일러스트 파일, 전투 대사 구조를 검사한다. 이 검사는 인물 해석의 정확성을 보증하지 않으며, 해석 근거는 위 자료와 수정 방향을 함께 검토해야 한다.
