# 열 레벨 전 구간 균형 조정 기록

검사일: 2026년 10월 25일

## 조건

- 일반 80개와 어려움 80개 모두 실제 카드 10레벨로 검사했다. 11·12레벨 강화로 문제를 우회하지 않았다.
- 시작 대원, 튜토리얼 발키리, 진입 전에 획득할 수 있는 장 보상만 사용했다. 어려움은 해당 장 일반 클리어 보상까지 포함했다.
- 기본 편성은 최고 등급 대원 없이 편성 인원과 비용 제한을 지킨다. 첫 장 이후에는 일반 제조 대원을 더 넣은 편성도 검사했다.
- 1초마다 판단하는 자동 지휘기가 발전 효율 두 단계 강화, 대원 출격, 포격을 수행했다. 사람의 실제 승률이나 모든 편성의 승리를 의미하지 않는다.
- 조정 때 사용한 두 패턴 외에 네 패턴으로 검증했다. 통과한 작전은 유지하고 수치를 다시 바꾼 작전만 재검사했다. 최종 기록은 작전별 현재 조정값과 일치함을 별도로 확인했다.

## 통과 기준

일반 첫 장 180초, 나머지 일반 210초, 어려움 240초, 각 장 마지막 작전은 300초 이내 승리. 남은 기지 체력은 일반 40%, 어려움 20% 이상이다. 실제 게임 제한 시간은 600초로 유지했다.

## 결과

| 구분 | 변경 전 기준 미달 작전 | 최종 통과 작전 |
|---|---:|---:|
| 일반 | 9 / 80 | 80 / 80 |
| 어려움 | 41 / 80 | 80 / 80 |

변경 전은 작전마다 한 패턴으로 검사했다. 최종 검사는 기본 편성 네 번씩 640회와 보강 편성 140회를 합쳐 780회이며, 모든 기록이 위 기준을 통과했다.

## 변경 내용

- 급습 증원을 시작 10초부터 세 기, 1.8초 간격으로 분산했다. 어려움의 첫 급습에는 추가 병력을 겹치지 않는다.
- 대군의 첫 출현을 5초로 늦추고, 출현 간격을 기본 간격의 60%로 조정했다.
- 64개 작전의 적 체력·공격력 또는 요새 체력을 개별 조정했다. 기지가 버티는데 전선이 교착하는 구간은 주로 적 체력과 요새 체력을 낮췄다.
- 적 조정 배율은 적 생성 때만 적용한다. 아군 기지 체력, 포격 위력, 처치 보상, 작전 경험치와 재화 보상은 함께 약해지지 않는다.
- 기존 요청인 출격 비용 절반, 대원 체력과 공격력 30% 감소는 유지했다.

## 어려움 네 번째 장 두 번째 작전

기본 보상 편성 네 차례 모두 승리했다. 전투 시간은 181.4~220.2초, 남은 기지 체력은 81.7~100.0%였다. 적 공격력 배율은 1로 유지했다.

## 기능 회귀 검사

- 브라우저 기능 검사 22개 전부 통과. 최종 수치 반영 뒤 다시 검사했다.
- 모든 대원의 비용·체력·공격력 비율, 편성 제한, 보상, 아군 기지 계산과 급습 초기 물량을 별도 검증했다.
- 제조 단독 검사에서 누락된 보조 정의와 오래된 천장 가정을 현재 구현에 맞춰 고쳤다. 게임 제조 규칙은 바꾸지 않았으며, 보조 검사와 브라우저 제조 검사가 모두 통과했다.
- 스토리 데이터 검사와 수정한 자바스크립트 문법 검사가 통과했다.

## 재현과 기록

로컬 개발 서버에서 `?unlock=1&audit=verify`로 검사한다. 실제 저장은 변경하지 않는다. 결과와 원시 기록은 아래에 보관한다.

- `tools/reports/campaign_baseline.json`: 변경 전 전체 검사
- `tools/reports/campaign_fit.json`: 1차 조정 결과
- `tools/reports/campaign_verify_round*.json`: 실패를 포함한 각 보완 이전 기록
- `tools/reports/campaign_verify.json`: 현재 수치의 최종 작전별 전투 기록
- `tools/reports/campaign_summary.json`: 최종 집계와 검사한 소스의 해시
- `tools/campaign_overrides.json`: 추가 패턴에서 발견한 문제의 보완값

일일 작전과 무한 전장은 이번 160개 작전 전수 조정 대상이 아니다. 기존 고정 편성과 성장 규칙을 유지하며 기능 검사에서 진입을 확인했다.
