## 크게 다른 6명 — 대표 대사 비교

**레프리콘**
- 원작: 「각하, 전, 각하가 브라우니 수준으로 떨어지지 않길 바랍니다.」 / 「바보를 살리는 게 제 일이죠.」
- 지금: 「들떠 있을 때가 아니야, 브라우니.」 / 「화염방사기라니, 다음 전장에선 든든하겠군. 환영한다.」

**발키리**
- 원작: 「딱히 잡담은 관심 없습니다.」 / 「스코프는 생존율을 낮출 뿐입니다.」
- 지금: 「감탄은 나중에. 사령관, 내 부대가 길을 열면 뒤를 받쳐 줘.」 / 「이의 없지?」

**운디네**
- 원작: 「봉쥬르. 내가 왔어! 전부 나한테 맡겨 두라구!」 / 「나? 인기 만점이었지.」
- 지금: 「안녕하세요, 사령관님. 운디네예요.」 / 「…저도 가끔은 따뜻한 게 좋아요.」

**레이븐**
- 원작: 「정말 너-무 좋아! 앞으로도 잘 부탁해 사령관~!」 / 「나랑 쇼핑이라도 갈까?」
- 지금: 「…늦었군. 나는 레이븐.」 / 「…사냥은 끝났다.」

**테티스**
- 원작: 「꺄하핫, 바다의 여신 테티스님이 등장했어요!」 / 「저는 애가 아니니까」
- 지금: 「테티스입니다. 이 회랑의 전력망을 분석해 왔어요.」

**흐레스벨그**
- 원작: 「안심하시죠 사령관님. 흐레스 벨그가 합류합니다.」 / 「제겐 무엇보다 소대원들의 생환이 가장 중요합니다.」
- 지금: 「…이 반응, 철충이 멈췄어. 오르카의 사령관이 해낸 거야?」

## 고칠 때 지킬 것 (가이드 규칙 요약)
- 호칭·존댓말 수준·1인칭은 원작 그대로, 한 캐릭터 안에서 섞지 않는다.
- 말버릇은 한 대사에 하나 정도로만 쓴다.
- 작전 정보(상성, 적 특성, 다음 목표)는 빼지 않고 캐릭터 말투로 바꿔 말한다.
- 이 게임의 역할(예: 운디네 = 냉각, 테티스 = 전격 분석)은 원작 성격 위에 얹는다.
