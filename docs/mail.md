# 우편함: 재화 보내는 방법

우편은 `js/mail.js`의 `window.MAILS` 목록에 적어서 보낸다. 목록에 항목을 추가해서 올리면, 기간 안에 접속한 플레이어의 우편함(로비 오른쪽 위 봉투 버튼)에 들어간다.

```js
{
  id: 'event-2026-11-01',             // 우편마다 다른 이름. 이미 쓴 id는 다시 쓰지 않는다(받은 기록이 id로 남는다)
  title: '11월 보급',                  // 제목
  body: '사령관님, 보급품입니다.',      // 내용
  reward: { parts: 2000, tuna: 500, xp: 1000, wild: { A: 10, S: 1 } }, // 부품 · 참치 · 경험치 · 와일드카드(B/A/S/SS), 필요한 것만
  from: '2026-11-01T00:00:00+09:00',  // 이때부터 보인다(한국 시간)
  until: '2026-11-07T23:59:59+09:00', // 이때가 지나면 받을 수 없다
},
```

- 한 번 받은 우편은 다시 받을 수 없다(세이브에 id가 남음).
- `until`이 지나면 '기간 만료'로 바뀌고 받을 수 없다. 만료된 우편은 7일 동안 목록에 회색으로 남았다가 사라진다.
- `from` 전에는 보이지 않는다. 미리 넣어 두고 날짜에 맞춰 열 수 있다.
- 받기 판정은 플레이어 기기의 시계를 쓴다.
